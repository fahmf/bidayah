# بنية البيانات

الملفّان في هذا المجلد مختلفان في طبيعتهما اختلافًا مقصودًا:

| الملف | من كتبه؟ | يُحرَّر باليد؟ |
|---|---|---|
| `nusus.js` | **ابن رشد** — مولَّد آليًا من `masdar/bidayah-thaharah.txt` | ❌ أبدًا. يُعاد توليده بـ `node tools/ingest.mjs` |
| `tahlil.js` | **المحرِّر** — طبقة تحليل فوق النص | ✅ نعم، وهذا موضع الإضافة |

القاعدة الحاكمة: كلُّ حقلٍ اسمه `nass` أو `matn` أو `jawab` يجب أن يكون **منقولًا بحروفه**
من المصدر، ويفحص ذلك `node tools/verify.mjs` فيسقط البناء إن اختلف حرف.
وكلُّ حقلٍ اسمه `sharh` فهو كلامُ المحرِّر، ويُعرض موسومًا بـ«شرح المحرِّر».

## وحدة في `nusus.js` (مولَّدة)

```js
{
  id: "th-002",                 // معرّف ثابت
  raqm: 2,                      // ترتيبها في كتاب الطهارة
  naw: "مسألة",                 // «مسألة» صرّح بها ابن رشد، أو «مبحث» عنونه المحرِّر
  unwan: "…",                   // عنوان مستخرج من صدر الكلام (يغلبه عنوان tahlil.js)
  kitab: "كتاب الوضوء",
  bab: "الباب الثاني معرفة أعمال الوضوء",
  mawdi: "ج١ ص١٥",              // موضع أول فقرة
  mawdi_kamil: "ج١ ص١٥ — ج١ ص١٥",
  fiqar: [{ matn: "…", mawdi: "ج١ ص١٥" }],   // كلامه مفقَّرًا، بحروفه
  nass_kamil: "…",              // الفقرات مجموعة
  nusus_zahira: [{ naw: "آية" | "حديث", matn: "…" }],  // ما التُقط آليًا من {…} و«…»
  sabab: { nass: "…", mawdi: "…" } | null              // فقرة «سبب اختلافهم» إن وُجدت
}
```

أرقام الصفحات محسوبة من علامات `# PageVxxPyyy` في المصدر، وهي توضع في **آخر**
الصفحة في صيغة OpenITI، فصفحةُ الفقرة = (صفحة آخر علامة قبلها) + ١، وتنتهي عند أول علامة بعدها.

## مدخلة في `tahlil.js` (يدوية)

```js
"th-002": {
  unwan: "هل النية شرط في صحة الوضوء؟",     // عنوان محرَّر يغلب العنوان الآلي

  mahall_al_ittifaq: [{ nass, mawdi }],       // ما نصّ على الاتفاق عليه
  mahall_al_nizaa:    { nass, mawdi },        // تحرير موضع الخلاف
  talkhis_al_aqwal:   { nass, mawdi },        // تلخيصه هو للأقوال (يُخفى في التدريب)

  aqwal: [{
    id: "q1",
    nass: "فذهب فريق منهم إلى أنها شرط",      // بلفظه
    qailun: [{ ism: "الشافعي", madhhab: "الشافعية" }],
    adilla: [{
      naw: "نقلي" | "عقلي",
      sinf: "قرآن" | "سنة" | "أثر" | "إجماع"
          | "قياس" | "استصحاب" | "مصلحة" | "دليل الخطاب" | "عمل أهل المدينة",
      matn: "…",                              // متن الدليل — يُعرض بالخط الكبير
      takhrij: "المائدة: ٦",                  // ليس نصًّا منقولًا، فلا يُفحص
      naw_al_dalala: "عموم" | "مفهوم" | "حصر" | …,
      wajh_al_istidlal: { nass?, sharh? },     // نصٌّ إن نصّ عليه، وشرحٌ إن احتاج
      itiradat: [{ nass, jawab }]
    }]
  }],

  sabab: {
    nass: "…", mawdi: "…",
    anwa: ["اشتراك الحرف"],                   // تصنيفٌ يربط المسألة بنظائرها
    sharh: "…"
  },

  tarjih: { nass, qail: "ابن رشد", mawdi },

  shajarat_al_istinbat: [{                    // صياغة المحرِّر، لا تُفحص حرفيًّا
    qawl_id: "q1",
    uqad: [{ naw: "نص" | "دلالة" | "قاعدة" | "حكم", matn: "…" }]
  }],

  tadrib: [{ suaal, khiyarat: [], sahih: 1, tafsir }],
  mustalahat: [{ kalima, sharh }]
}
```

## تصنيف `anwa` — أسباب الاختلاف

يتبع ما عدّه ابن رشد في مقدمة الكتاب، وهو أنفعُ ما في الموقع لبناء الملكة:
الضغط على وسم النوع يعرض **نظائر المسألة** في سائر الكتاب. من المستعمل حاليًا:
اشتراك الاسم، اشتراك الحرف، خفاء تناول الاسم للمحل، تردد الفرع بين أصلين،
معارضة الزيادة لظاهر الآية، تعارض القول والفعل، اختلاف القراءات، تعارض الظاهرين،
اختلاف الرواية، الاختلاف في تصحيح الأثر، قبول زيادة الثقة، تعارض ظواهر الأحاديث،
اشتراط اشتهار العمل بخبر الآحاد.

## إضافة كتاب جديد

1. نزِّل نص الكتاب من مدونة OpenITI (نفس النسخة: الشاملة ٢١٧٣٩) واقتطع الكتاب المراد إلى `masdar/`.
2. عدّل حدود الاقتطاع في `tools/ingest.mjs` ثم شغّله.
3. أضف مدخلات التحليل في `tahlil.js` على البنية أعلاه.
4. شغّل `node tools/verify.mjs` — ولا تدفع شيئًا وهو يشتكي.
